# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website developed to showcase my **technical skills, academic projects, education, experience, and professional profile**.

The website is designed to provide a professional online presence for internship and career opportunities.

I am interested in:

* 💻 Web Development
* ☕ Software Engineering

* 🤖 Artificial Intelligence
* 🔐 Cybersecurity
* 🎨 UI/UX Design

## 🎯 Project Purpose

The main purpose of this portfolio website is to:

* Showcase my technical skills

* Display my educational background

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/DinukIsuranga/portfolio-website.git
```

### 2. Open the project

```bash
cd portfolio-website
```

### 3. Run the website

Open:

```text
index.html
```

in a modern web browser.

Alternatively, use **Visual Studio Code Live Server** to run the website locally.
